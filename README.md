## 🚀 Key Features

- **Global & Indian DSP Distribution**:
  - Spotify, Apple Music, YouTube Music, Amazon Music, JioSaavn, Wynk Music, Gaana, Hungama Music, Resso, Deezer, SoundCloud.
  - Social platforms: Instagram Reels, Facebook Audio Library, Moj, Josh.
  - Caller Tunes (CRBT): Jio, Airtel Wynk, Vi, BSNL networks.
- **71+ Managed YouTube Channels**:
  - Complete directory with dynamic search, category filtering (Artist, Bhakti, Music, Films, Entertainment), subscriber count sorting, and pagination.
- **User Authentication Portal**:
  - Email & Password Sign In with "Remember Me"
  - Quick 1-Click Demo Artist Login
  - Continue with Google / Gmail integration
  - Sign Up (Registration) with account category selection (Artist, Label, Producer, Channel Manager)
  - Forgot Password flow with instant 6-digit OTP code verification
- **Artist & Creator Dashboard**:
  - Live Catalog & Track Status (ISRC, UPC, Delivery Status on DSPs)
  - Royalty & Analytics Breakdown by Platform
  - Connected Streaming Store Badges
  - In-App Track Submission Form
- **Modern UI / UX**:
  - Built with React 18, Vite, Tailwind CSS, and Framer Motion
  - High-performance responsive design across desktop, tablet, and mobile devices
  - Infinite marquee ticker of supported platforms
  - Interactive FAQ accordion & animated counters

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite

- **State Management**: React Context API with LocalStorage persistence

## 💻 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/Sandeepmishra2396/rk-digital-media.git
cd rk-digital-media
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
